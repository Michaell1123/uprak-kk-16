Eksplorasi Teknologi Jaringan Komputer, Infrastruktur, dan Administrasi Sistem

Infrastruktur Jaringan LAN & WAN

Jaringan komputer adalah sistem yang menghubungkan beberapa perangkat komputer agar dapat saling berbagi sumber daya, data, dan informasi.

  • LAN (Local Area Network): Jaringan komputer yang mencakup wilayah kecil, seperti dalam satu ruangan, kantor, atau laboratorium sekolah. Menggunakan media kabel UTP atau Wi-Fi lokal.
  • WAN (Wide Area Network): Jaringan yang mencakup area geografis yang sangat luas, antar kota, bahkan antar negara, umumnya menggunakan teknologi router dan leased line.
  • Topologi Jaringan: Pola hubungan antar perangkat dalam jaringan, meliputi topologi Star (Bintang), Bus, Ring, Mesh, dan Tree.

Konsep Routing & Subnetting IP

Routing adalah proses pengiriman paket data dari suatu jaringan ke jaringan lain melalui router. Sementara Subnetting adalah teknik memecah jaringan besar menjadi beberapa sub-jaringan yang lebih kecil.

  • IPv4 & IPv6: Alamat pengenal unik untuk setiap perangkat di jaringan internet (Contoh IPv4: 192.168.1.1).
  • CIDR (Classless Inter-Domain Routing): Penulisan prefiks subnet mask, misalnya /24 yang berarti netmask 255.255.255.0.
  • Routing Statis vs Dinamis: Routing statis dikonfigurasi secara manual oleh administrator, sedangkan routing dinamis (OSPF, BGP) memperbarui jalur secara otomatis.

Teknologi Fiber Optic

Fiber Optic adalah media transmisi data yang menggunakan kabel kaca atau plastik halus untuk mentransmisikan sinyal cahaya dari satu tempat ke tempat lain berkecepatan tinggi.

  • Single-Mode Fiber: Inti kabel sangat kecil, digunakan untuk transmisi jarak jauh dengan kapasitas besar (antar kota/pulau).
  • Multi-Mode Fiber: Inti kabel lebih besar, umum digunakan untuk jaringan jarak dekat seperti antar gedung dalam satu kawasan kampus.
  • Perangkat Pendukung: Media Converter, OLT (Optical Line Terminal), ONU/ONT di sisi pelanggan, serta SFP Module.

Administrasi Server & Linux

Sistem operasi jaringan berbasis teks (CLI) seperti Linux Debian atau Ubuntu menjadi standar industri dalam mengelola layanan server jaringan.

  • DHCP Server: Layanan yang memberikan alamat IP secara otomatis ke komputer klien.
  • DNS Server (BIND9): Menerjemahkan alamat IP numerik menjadi nama domain yang mudah dibaca manusia (contoh: smkbanjarasri.sch.id).
  • Web Server (Apache/Nginx): Menyiarkan halaman website agar dapat diakses melalui protocol HTTP/HTTPS.
