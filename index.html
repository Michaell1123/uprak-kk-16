Eksplorasi Teknologi Jaringan Komputer, Infrastruktur, dan Administrasi Sistem

Infrastruktur Jaringan LAN, WAN & Topologi

Jaringan komputer adalah sistem yang menghubungkan beberapa perangkat komputer agar dapat saling berbagi sumber daya, data, dan informasi secara efisien.

  • LAN (Local Area Network): Jaringan komputer yang mencakup wilayah kecil, seperti dalam satu ruangan, kantor, atau laboratorium sekolah menggunakan media kabel UTP atau Wi-Fi lokal.
  • WAN (Wide Area Network): Jaringan yang mencakup area geografis yang sangat luas, antar kota, hingga antar negara, umumnya menggunakan teknologi router dan leased line.
  • Topologi Jaringan: Pola hubungan antar perangkat dalam jaringan, meliputi topologi Star (Bintang), Bus, Ring, Mesh, dan Tree yang menentukan alur komunikasi data.

Teknologi Fiber Optic & Server Linux

Mempelajari media transmisi cahaya berkecepatan tinggi serta dasar pengelolaan layanan server jaringan berbasis sistem operasi teks (CLI).

  • Fiber Optic: Media transmisi data menggunakan serat kaca/plastik halus. Terdiri dari Single-Mode (jarak jauh/antar kota) dan Multi-Mode (jarak dekat/antar gedung).
  • DHCP Server: Layanan otomatisasi yang mendistribusikan alamat IP kepada setiap komputer klien di dalam jaringan.
  • DNS Server (BIND9) & Web Server: DNS menerjemahkan IP numerik menjadi nama domain (misal: smk.sch.id), sementara Web Server (Apache/Nginx) menyiarkan halaman web via HTTP/HTTPS.

Routing, Subnetting & Simulasi Jaringan

Routing adalah proses pengiriman paket data antar jaringan, sementara subnetting memecah jaringan besar menjadi sub-jaringan yang lebih terstruktur.

  • IPv4 & CIDR: Alamat pengenal unik perangkat (contoh: 192.168.1.1) dengan penulisan prefiks subnet mask seperti /24 (255.255.255.0).
  • Routing Statis & Dinamis: Konfigurasi jalur paket data secara manual oleh admin ataupun secara otomatis oleh protokol dinamis (OSPF/BGP).
